Design decisions on this screen

  • No typing where avoidable — number pad only for weight, tap-chips for status, voice-note for remarks (workshop hands are often busy or dirty).
  • Karigar sees only his own jobs — no cross-karigar data, no math to do. He reports facts; the office system runs reconciliation.
  • Hindi-first microcopy — matches real shop-floor language, not translated enterprise English.
  • Large tap targets, high contrast — deliberately breaks the desktop enterprise design system (dense, neutral) because this is a different user and context.
  • Immediate confirmation — WhatsApp-style reassurance closes the loop so the karigar isn't left wondering if it worked.
